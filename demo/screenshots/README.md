# Demo screenshots

The screenshots referenced by the presentation are not included yet. Capture
them from the running local dashboard after `make demo` and starting the API
and dashboard as described in the root README.

1. Open the dashboard at `http://127.0.0.1:5173/`.
2. Capture the populated overview as `dashboard_overview.png`.
3. Select the high-risk review and capture its score, signals, evidence, and
   explanation as `dashboard_selected_review.png`.
4. Capture the completed decision state as `dashboard_decision.png`.

Save PNG files in this directory. Do not use screenshots containing real
repository data or secrets; the demo database is isolated.
