// just-in-time defect prediction

Know which pull request will break something — before it merges.

PR Risk Scorer reads a diff, scores it for defect risk, shows exactly why, and points to the closest past commit that caused the same kind of bug. Runs fully offline. Your code never leaves your machine.

Install locally See how it scores a diff

01 — pipeline

Score, explain, recommend. Never just a label.

A bare 1 or 0 tells a reviewer nothing. Every stage below exists to turn a prediction into something a human can act on.

01Read the diff

Pulled straight from git — commit range, PR, or working tree.

02Extract features

Diff size, files touched, author's bug history, test coverage.

03Score it

CodeBERT + a handcrafted-feature baseline, blended into one weighted score.

04Find evidence

RAG search over labelled history for the closest past bug-inducing commit.

05Explain it

An LLM turns the score and evidence into plain English and a concrete fix.

06You decide

Approve, request changes, or escalate — logged, always human-final.

02 — the review card

What a reviewer actually sees

Not a dashboard full of numbers. One card per pull request, with the reasoning right next to the verdict.
